# 2026-11-09

## 博客从 Vercel 迁移到腾讯云

### 背景

Vercel 没有中国大陆节点（响应头 `x-vercel-id: kix1::iad1`：边缘在大阪、
SSR 函数在美东），国内访问首屏 4~5s、静态资源 20~30s。域名已在阿里云备案，
腾讯云上运行着博客 Agent，决定把博客本体迁到同一台服务器。

### 服务器

- 4 核 / 3.6G 内存 / 2G swap / 40G 磁盘，Node v22、Nginx、Certbot、Docker 已就绪
- Agent 两个进程约 300MB；MinerU 解析服务空闲，Nuxt 常驻约 100~140MB
- PM2 新增 `blog` 进程，`max_memory_restart: 700M`，监听 `127.0.0.1:3000`

### 部署

- 本地 `NITRO_PRESET=node-server npm run build`，只上传 `.output` 到
  `/opt/ai-myhome-blog`，不在服务器上跑 `nuxt build`
- Nitro 产物缺少被 npm 提升的传递依赖（`property-information`），
  在服务器上补 `npm ci --omit=dev`，依赖装在应用根目录
- `deploy/start.sh` 加载服务器 `.env`（600）后启动 `server/index.mjs`
- `deploy/ecosystem.config.cjs`：`AGENT_BASE_URL=http://127.0.0.1:8000`、
  `TWIKOO_BACKEND=http://127.0.0.1:8080`
- 部署脚本：`bash deploy/deploy-blog.sh`

### Nginx / HTTPS

- `ai-myhome.space`、`www` 反代到 3000；`/_nuxt`、`/fonts`、`/vendor`
  直接读磁盘并长缓存；`/api/agent` 关闭 buffering、超时 300s（SSE）
- 开启 **HTTP/2 + gzip**（含反代 HTML/JSON），这是首屏从 19s 降到 2s 的关键
- Certbot 签发 `blog-test`、`ai-myhome.space`、`www.ai-myhome.space` 证书，
  HTTP 自动跳 HTTPS
- DNS：`ai-myhome.space` / `www` A 记录指向 `106.55.76.235`
- 回滚：Vercel 部署仍在，DNS 改回 `cname.vercel-dns.com`

### Twikoo 评论自建

- 迁站后发现腾讯云访问不了 Twikoo 的 Vercel 后端
  （`message-board-pi-pearl.vercel.app` fetch failed；`vercel.com` 正常，
  但项目边缘 IP 拒绝/超时），评论接口 502
- 自建：`imaegoo/twikoo:2.0.17` Docker（LokiJS 本地存储，无需 MongoDB），
  只监听 `127.0.0.1:8080`，数据卷 `twikoo-data`
- 前端 `/vendor/twikoo.all.min.js` 从 1.7.24 升到 **2.0.17**
  （1.7 前端调 `GET_COMMENTS`，2.0 服务端只认 `COMMENT_GET`）
- 博客代理 `server/api/twikoo/proxy.ts` 改为读 `TWIKOO_BACKEND`
- 旧评论迁移完成：用旧后台管理员密码登录，调 `COMMENT_GET_FOR_ADMIN`
  导出 8 条（7 条主评论 + 1 条回复），再通过 2.0.17 的
  `COMMENT_IMPORT_FOR_ADMIN`（`source: twikoo`）导入新库
- 新后台原本未设置管理员密码，迁移时设为与旧后台相同的密码；
  登录后台后建议改成新密码
- 新库还有 1 条迁站后的测试评论，管理端共 9 条；
  首页留言板渲染 8 条主评论 + 1 条嵌套回复，无 console 报错

### 首屏优化

- 头像 `avatar.png` 2364×1773 / 2.9MB → `avatar.webp` 448×448 / **13KB**
- Geist 字体从 Google Fonts 改为自托管（8 个 woff2，约 212KB），
  移除 `fonts.googleapis.com` / `fonts.gstatic.com` 外链
- 生产构建冷启动实测：HTML TTFB 79ms，load **2.2s**（迁移前 19~30s）；
  缓存后首页 112ms
- 留言板仍是滚动懒加载：滚动前 0 个 vendor 请求，滚动后加载并渲染

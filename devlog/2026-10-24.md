# 2026-10-24

## 聊天页：模型失败时显示错误（不再空白气泡）

### 问题

豆包 `doubao-seed-2-0-lite-260215` 2026-10-22 下线后，线上聊天「发送了没反应」：用户消息发出去了，AI 那边一片空白。

后端其实有错误输出：流已经开始时 HTTP 状态码改不了，只能以 SSE 错误块收尾：

```
data: {"error": {"message": "生成失败: ..."}}
```

但前端 `ChatPanel.vue` 的解析器只认 `choices`（正文）、`sources`（参考资料）、`chars`（字数额），`error` 键落到 else 分支后什么也匹配不上，被静默跳过 —— 空占位气泡就一直空着。

### 修复

- `components/agent/ChatPanel.vue`：解析循环里识别 `parsed.error`，抛给 `send()` 外层已有的 catch —— 删掉空占位气泡 + 顶部红色错误横幅（和网络错误同一套 UI）
- 顺带修正模型文案：空状态欢迎语与 `server/utils/llm.ts` 的模型名从 2.0-Lite 改为 2.1-Lite（下拉列表也一起）

### 踩坑

原解析循环的 `try/catch` 是为 `JSON.parse` 兜底（心跳等非 JSON 行直接跳过）。如果直接在 `try` 里对 `error` 块 `throw`，会被这个 `catch` 自己吞掉，外层永远收不到。

解决：把 `try` 收窄成只包 `JSON.parse`，错误判断放到 `catch` 外面，再抛给外层。

### 验证（puppeteer + 本地 mock SSE）

| 场景 | 期望 | 结果 |
|---|---|---|
| 只收到错误块 | 红条提示，无空白气泡 | ✅ |
| 半截回答后出错 | 红条提示 + 保留半截回答 | ✅ |
| 正常流式 | 无红条，正常显示回答 | ✅ |

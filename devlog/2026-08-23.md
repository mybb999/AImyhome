## 遇到的问题

1. **Bug**：首页/聊天工具 → 博客快速切换（BlogSidebar 文章列表未渲染完时切回）时，AvatarCard（个人简介）被渲染到 `aside` 外部、页面底部，aside 变空。
   **根因**：`components/blog/BlogSidebar.vue` 使用 `await useFetch` 使组件成为异步组件（挂起在 Suspense 中）。挂起未 resolve 时组件被卸载（路由切走），数据返回后 Vue 将 aside 的 v-if 分支内容插入到错误父节点（布局根 `div.min-h-screen`），导致 AvatarCard 被挤出 aside。「out-in」页面过渡放大了被打断的概率。
   **修复**：移除 BlogSidebar 中的 `await`，改为非阻塞 `useFetch`（与 BlogList 一致，`default: () => []` 已处理 pending 状态），组件不再挂起。
   **验证**：Playwright + Edge 无头复现（CPU 节流 4x + /api/blog 延迟 1s + 60~250ms 弹回切换），修复前稳定复现、修复后全时序干净；`npm run build` 通过。

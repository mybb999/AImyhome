## 遇到的问题

1. **Windows 构建 bug**：`npm run build` 报 `RangeError: [nuxt:components:imports] path should be a path.relative()d string, but got "f:/AIproject/AImyhome/vite/preload-helper.js"`。
   **排查**：清 `.nuxt` 缓存无效 → 二分定位到 08-24 凌晨新增的根 `tsconfig.json`（`extends: ./.nuxt/tsconfig.json`）。继承来的 `include: ["../**/*"]` 全项目通配在 Windows 上触发 Nuxt 3.12.4 已知虚拟模块 bug 家族（nuxt/nuxt #25261 / #28262：`\0` 前缀虚拟模块 id 传入 ignore 包抛 RangeError）。单变量实验验证：移走 tsconfig → 构建通过；保留 extends + 覆盖 include → 构建通过。
   **修复**：根 tsconfig 覆盖 `"include": ["."]`，保留完整 extends（IDE 全量类型支持不受影响）。
   **教训**：Windows + Nuxt 3.12.4 上，根 tsconfig 继承 `.nuxt/tsconfig.json` 时必须覆盖 include；且 dev 服务器运行（尤其强杀）后 `.nuxt` 可能残留损坏状态，构建前需 `rm -rf .nuxt`。两者叠加（修复 tsconfig + 清缓存）才能稳定构建。Vercel（Linux）构建不受影响。
2. **免费档限制**：GLM-4.7-Flash 免费档有并发/速率限制，高峰期间歇性 1305「访问量过大」，连续请求触发速率限制。已加重试一次缓解；属免费档固有特性，如追求稳定可考虑付费档或换豆包。
3. 官方文档站 docs.bigmodel.cn、github.com 从本环境均无法访问（网络策略拦截），模型信息通过搜索交叉核实、行为通过实测验证。
